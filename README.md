# 稻盛和夫经营哲学

稻盛和夫经营哲学的一页式介绍网页：生平时间轴、核心哲学、成功方程式（含交互演示）、经营十二条、六项精进、阿米巴经营与会计七原则、经典语录与代表著作。

## 本地预览

直接双击打开 `index.html` 即可，或在目录下运行：

```bash
python3 -m http.server 8000
```

访问 http://localhost:8000

## 在线访问（GitHub Pages）

部署后访问：`https://<你的用户名>.github.io/inamori-philosophy/`

- 生平事实整理自人民网、京瓷官网讣告、澎湃新闻、财新网等公开报道
- 经营哲学内容整理自稻盛和夫公开著作《活法》《干法》《心》《六项精进》《阿米巴经营》《京瓷哲学》等
